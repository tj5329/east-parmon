# Hardwood Dynasty (east-parmon)

Interactive text-based basketball simulation inspired by MyNBA/MyGM style modes.

## Features
- **GM mode**: manage roster, train players, simulate seasons, and chase championships.
- **Player Career mode**: control one player, run workouts, and build a legacy.
- **Coach Career mode**: set schemes, improve coach IQ, and guide your team.
- **Real NBA seed data**: includes real teams, coaches, and star players.
- **Generated rookie classes** after seasons for long-term dynasty play.
- **Encrypted-style player face IDs and coach avatar IDs** using deterministic SHA-256 hashes.

## Run
```bash
python3 game.py
```

## Notes
- This is a lightweight terminal game (no graphics engine).
- Ratings, records, and progression are simulation-driven with randomness.
